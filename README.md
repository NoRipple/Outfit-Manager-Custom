# 穿搭管理器 Outfit Manager

SillyTavern 穿搭管理插件 —— 让 AI 不再为角色乱编服装。

当前版本：2.6.1

## 更新日志

### 2.6.1

- 修复大图预览被聊天区盖住的问题：预览层改为挂到页面最外层、全屏固定显示，层级最高，点卡片或正文卡片行都能正常全屏查看。
- 新增「要求 AI 标注本楼穿搭」开关（设置 → 发送内容，默认开启）：注入时附上当前可用穿搭的名称清单，并约定回复末尾输出 `<Outfit-Manager-Custom>名称/角色+名称/角色</Outfit-Manager-Custom>`，插件再把这段渲染成可点卡片行。关掉后 AI 不会收到这条规约。

### 2.6.0

- 魔法棒菜单新增「当前生效穿搭」按钮：点开后在**左下角**弹出一个浮窗，列出此刻真正参与注入的每一套穿搭（缩略图 + 角色名 + 穿搭名 + 标签），点卡片直接看大图。窗口会自动避开对话区，左侧空间不足时收成图标条，不会压住正文。
- 支持正文穿搭标记：AI 在回复里写 `<Outfit-Manager-Custom>穿搭名称1/角色1+穿搭名称2/角色2</Outfit-Manager-Custom>`，插件会把它渲染成一行可点的穿搭卡片（角色名 + 名称 + 标签），点击看大图；对不上的名字会显示「未找到」提示，不会影响正文其它内容。

### 2.5.0

- 新增「全选激活 / 激活选中」：批量栏里一键把当前衣柜的全部穿搭（或选中的几套）设为激活，不用一套套点。
- 发送给 AI 的内容类型改为三档：**仅标签** / **标签 + 文字** / **标签 + 文字 + 图片**，标签始终发送；旧配置自动迁移（原来选「仅图片」或「文字 + 图片」的会变成「标签 + 文字 + 图片」）。
- 修复单套模式下标签没被注入的问题：现在无论几套，标签都会带在服装信息最前面。
- 新增「通过酒馆代理发送」开关：本地大模型服务（如 `http://127.0.0.1:3425`）报 `Failed to fetch` 时打开，请求改走酒馆自带的反向代理，绕过浏览器 CORS 限制。

- 「标签管理」面板的服装组按单品分组展示：能看到每个单品的使用套数与它下面各二级词的套数，可单独删某个二级词或整个单品。
- 批量设置标签的服装组支持「单品」或「单品/二级词」两种写法（如 高领衫 或 高领衫/驼色）。

- 旧数据自动兼容：之前的扁平服装标签会自动转成「单品 + 空二级词」，无需手动迁移。

## 这个插件解决什么问题？

在 SillyTavern 角色扮演中，AI 经常自行编造角色的服装描写，导致人设崩坏。比如你设定的是穿西装的总裁，AI 可能下一句就给他换上了休闲T恤。

穿搭管理器通过将你预设的穿搭信息注入到 AI 的对话上下文中，确保 AI 严格按照指定的服装来描写角色。

## 功能特性

- **User / 角色独立穿搭**：User 和每个角色各有独立的穿搭管理
- **衣柜模式**：为同一角色设置多套穿搭，AI 根据场景标签自动匹配，场景转换时切换穿搭
- **单品管理**：发型、妆容、美甲、饰品、道具等可作为单品单独保存、分类、移动、复制和生成描述
- **套装方案**：在已有穿搭主体上保存一组单品搭配，点选单品只是临时选择，点击保存套装后才写入数据
- **三种注入方式**：纯文字 / 纯图片 / 文字+图片
- **三种注入位置**：系统提示末尾 / 上下文末尾 / 用户消息末尾（推荐）
- **多维标签**：每套穿搭可打「场景 / 服装 / 气质」三组多选自由标签，供搜索、筛选和 AI 生成使用
- **场景标签系统**：为穿搭标记适用场景（如"外出"、"家居/睡前"），衣柜模式下 AI 按标签选择穿搭
- **通用衣柜**：通用衣柜常驻，可与角色单人衣柜配合使用
- **风格衣柜**：角色衣柜名称自由命名，可按风格分类（总裁类、校园类、年下类等）
- **图片转描述**：支持调用 API 将穿搭图片自动生成文字描述
- **分类管理**：穿搭支持自定义分类，方便整理
- **角色数据导入/导出**：支持按角色导出穿搭数据，方便分享和备份
- **可自定义模板**：注入给 AI 的提示词模板完全可编辑

## 安装方法

### 方法一：通过 Git 安装（推荐）

1. 打开 SillyTavern，进入 **扩展** → **安装扩展**
2. 输入本仓库的 Git 地址，点击安装

### 方法二：手动安装

1. 下载本仓库的 ZIP 文件
2. 解压后将文件夹放入 SillyTavern 的 `public/scripts/extensions/third-party/` 目录
3. 重启 SillyTavern

## 使用指南

### 基础用法（单套穿搭）

1. 点击侧栏的穿搭管理器按钮打开面板
2. 点击 **添加穿搭**，输入名称和文字描述（或上传图片）
3. 勾选激活这套穿搭
4. 开始聊天，AI 就会按照你设定的穿搭来描写

### 角色穿搭

1. 在角色选择器中选择或输入角色名
2. 为该角色添加穿搭
3. User 和角色的穿搭会合并后一起注入给 AI

### 衣柜模式（多套穿搭）

1. 为同一角色添加多套穿搭
2. 全部勾选激活
3. 建议为每套穿搭添加 **场景标签**（如"办公室"、"居家"、"外出"）
4. AI 会根据当前剧情场景选择最合适的穿搭，场景转换时自动切换

### 单品和套装

1. 切换到单品栏，添加发型、妆容、美甲、饰品、道具等单品
2. 单品可以独立分类，也可以批量导入并生成描述
3. 先选择一个穿搭主体，再点选要搭配的单品
4. 点击保存套装后，当前主体会记录这组单品搭配；未保存前只是临时选择

### 推荐设置

- **注入方式**：纯文字（最稳定）
- **注入位置**：用户消息末尾（Gemini/DeepSeek 兼容性最佳）
- **单套穿搭**：所有模型均稳定支持
- **衣柜模式**：文字模式下可用，纯图片模式下不建议使用衣柜

## 后端存储建议

默认 IndexedDB 本地存储已经可以使用。图片和衣柜数据较多、需要跨设备迁移，或希望减少浏览器本地存储压力时，建议安装配套后端 `Outfit-Manager-Server`。

使用后端前请确认 SillyTavern 已开启 server plugin，并定期备份后端插件目录下的 `data/`。如果后端不可用，插件会尽量回退到本地存储；恢复后端前建议先导出完整备份。

后端建议通过 Git 安装，并在 SillyTavern 的 `config.yaml` 中启用 `enableServerPluginsAutoUpdate: true`。SillyTavern 会在启动时尝试更新 server plugin；穿搭管理器检测到后端低于最低兼容版本时会提示重启或检查自动更新设置。ZIP/手动复制安装的后端不能依赖该更新机制。
